# Stakeholder Analysis — MedChain (Draft v0.1)

## Stakeholder Map

| Stakeholder | Type | Interest | Influence |
|-------------|------|----------|-----------|
| Patient | End User | Access own records, control privacy | High |
| Doctor | End User | Fast record & prescription creation | High |
| Pharmacist | End User | Verify and dispense prescriptions | High |
| Clinic Admin | Operational | Manage clinic's doctors | Medium |
| Pharmacy Admin | Operational | Manage pharmacy's pharmacists | Medium |
| Platform Admin | Operational | Approve accounts, view stats (no medical content) | High |
| DEPI / Instructor | Sponsor | Project quality & on-time delivery | High |
| Regulatory Bodies | Contextual | Data protection compliance (e.g., Law 151/2020) | Medium |

## Key Expectations

- **Patients:** single source of truth + full control over access.
- **Doctors & Pharmacists:** speed and accuracy in daily workflow.
- **Admins:** visibility without exposure to medical content.
- **Sponsor:** working demo + documented delivery.

## Communication Needs

| Group | Need | Channel |
|-------|------|---------|
| End Users | Simple, clear UI | In-app messages |
| Admins | Operational visibility | Dashboard |
| Sponsor | Progress at milestones | Reviews |

> Initial draft — stakeholder roles and expectations may evolve.
